# **Workspace Optimizer**

## **Background**
The modern workplace is evolving with the rise of remote and hybrid working models.  
Our **Dabur office**, like many others, faces **space constraints**, leading to:  
- **Overcrowding**  
- **Lack of available seating for employees**  
- **Disrupted productivity**  

To address these challenges, we developed a **Workspace Optimizer** using the **MERN (PostgreSQL, Express.js, React.js, Node.js)** stack.  
This tool provides **real-time information** on seat availability, enabling employees to:  
- Plan their workdays effectively.  
- Reduce overcrowding.  
- Improve resource utilization.  
- Enhance workplace efficiency.

## **Project Functionalities**
This project was a collaborative effort of **three members** to tackle space constraints by providing real-time seat availability information.  

### **Key Features**
#### **Login Page**
- Access for both **admin** and **registered users**.  
- **Admin Users**:  
  - Predefined passwords and exclusive access rights.  
- **Registered Users**:  
  - Create their own **alphanumeric username** and **password** during registration.  

#### **User Page**
- Features **two main options**:  
  1. **My Booking**  
     - View booking details (date and time duration).  
     - **Single booking restriction** per user at a time.  
  2. **Reservation**  
     - Reserve a table or workspace (limited to **one day in advance**).  

#### **Admin Page**
- Displays all user details:  
  - Usernames, booking dates, and times.  
- **Admin Restrictions**:  
  - Can **monitor bookings** but **cannot delete reservations**.
